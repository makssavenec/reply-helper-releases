Reply Helper — Privacy Policy

Last updated: 2026

What data is processed

When you select text on a supported page and request a reply suggestion, the selected text (and, if enabled, a limited amount of surrounding conversation context from the same page) is sent directly from your browser to the xAI Grok API (api.x.ai) to generate a response suggestion. This data is not sent to, or stored by, the extension developer or any third party other than xAI.

API key

Your xAI API key is stored only locally in your browser's extension storage (chrome.storage.local). It is never transmitted anywhere except directly to api.x.ai as part of your own API requests.

Local settings sync (optional)

If configured, the extension may periodically fetch a small configuration file (tone/model preference) from a GitHub Gist URL you control, and a version-check file to notify you of extension updates. No personal data is included in these requests.

No analytics or tracking

This extension does not use analytics, does not track browsing history, and does not collect or transmit any personal data to the developer.
